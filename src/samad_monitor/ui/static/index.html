به محض اینکه اداره تغذیه دانشگاه شهید بهشتی منوی هفته آینده را ثبت کند، سیستم آن را تشخیص داده و در تلگرام و ویندوز ۱۱ به شما اطلاع می‌دهد.

⚠️ توکن ربات تلگرام هنوز ثبت نشده است: ابتدا در تب «⚙️ تنظیمات آسان (.env)» توکن ربات خود (از @BotFather) و پورت پروکسی فیلترشکن را ذخیره کنید تا بتوانید دوستانتان را اضافه نمایید.

🔗 دعوت سریع دوستان (با دکمه Start ربات)

دوستانتان کافی است وارد ربات تلگرام شما شوند و دکمه Start را بزنند! کیبورد فارسی ربات در پایین تلگرام باز می‌شود و می‌توانند با زدن «📅 منوی هفته قبل» بین دو دکمه شیشه‌ای «🏠 منوی سلف خوابگاه» و «🏛 منوی سلف مرکزی» انتخاب کنند.

اگر کد بگذارید، فقط کسانی که از طریق لینک دعوت بالا وارد ربات شوند خودکار عضو می‌شوند.

➕ افزودن دستی شخص، گروه خوابگاه یا کانال

نکته مهم تلگرام: اشخاص حقیقی باید حتماً یک بار در ربات شما دکمه Start را زده باشند (برای گروه/کانال، ربات را عضو یا ادمین کنید).

۱️⃣ راه‌اندازی اولیه روی ویندوز ۱۱ (فقط یک بار)

  1. پوشه پروژه samad-food-monitor را روی کامپیوتر خود باز کنید.
  2. روی فایل 1_Install_Windows.bat دوبار کلیک کنید (یا دستورات زیر را در PowerShell بزنید):
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -e .
playwright install chromium

سپس برای باز کردن همین پنل گرافیکی روی کامپیوتر خود، کافی است روی فایل 2_Start_Dashboard_Windows.bat دوبار کلیک کنید!

۲️⃣ اتصال اکانت سماد و ربات تلگرام

  1. در تب «تنظیمات آسان» همین پنل، توکن ربات تلگرام (از @BotFather) و Chat ID خود (از @userinfobot) و پورت پروکسی فیلترشکن را وارد و ذخیره کنید.
  2. روی دکمه «🔔 تست اعلان» بالای صفحه کلیک کنید تا پیام تست روی گوشی و دسکتاپ ویندوز ۱۱ شما بیاید.
  3. روی دکمه «🔐 ورود دستی به سماد» کلیک کنید؛ در پنجره کرومیوم بازشده وارد حساب دانشگاه شهید بهشتی شوید تا نشست شما به‌صورت امن ذخیره شود.
  4. روی دکمه «🔎 بررسی فوری منوی هفته آینده» کلیک کنید!

۳️⃣ اجرای کاملاً خودکار و مخفی بعد از روشن شدن ویندوز ۱۱

اگر می‌خواهید حتی بدون باز بودن این صفحه هم ویندوز ۱۱ به محض روشن شدن، در پس‌زمینه (بدون هیچ پنجره سیاه مزاحمی) منوی سماد را چک کند، یک بار این دستور را در PowerShell داخل پوشه پروژه اجرا کنید:

powershell -ExecutionPolicy Bypass -File .\scripts\install_windows_task.ps1

هر زمان خواستید اجرای خودکار ویندوز را متوقف کنید، کافی است uninstall_windows_task.ps1 را اجرا نمایید.
